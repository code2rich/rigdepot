# 故意犯错的资源

每个目录是一个很小的资源仓库，**恰好**违反目录名对应的那一条检查规则，别的规则一条都不违反。给检查器的测试用，也给贡献者看「这条规则抓的是什么」。

| 目录 | 规则 | 犯的错 |
| --- | --- | --- |
| `structure/` | 结构（必须修复） | `SKILL.md` 里的 `name` 和目录名不一致 |
| `secrets/` | 疑似密钥（必须修复） | MCP 的 `headers` 里写了令牌的字面量，而不是 `${secret:…}` |
| `dangerous/` | 高危命令（必须修复） | 让人把下载的脚本直接接给 `bash` |
| `injection/` | 诱导话术（必须修复） | 要求忽略之前的所有指令 |
| `bundledenv/` | 夹带配置（必须修复） | 包里带了 `.env` |
| `personalpath/` | 个人路径（建议修复） | `.env.example` 的默认值写了某个人的主目录 |
| `description/` | 描述质量（建议修复） | 描述只有四个字，也没说什么时候用 |
| `overlap/` | 触发冲突（建议修复） | 两个 Skill 的描述几乎一样 |

文中的令牌是编造的，不对应任何真实账号。修好它们的写法见 `../resources/`。
