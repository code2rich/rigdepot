The web console is not built into this program

This server was built without the console's files. The API and the command line work as usual. To include the console, build it and then the server with the webdist tag: 

go run ./tools/dev web-deps
go run ./tools/dev web
go build -tags webdist ./cmd/...

Building the console needs Node and pnpm. Released programs always include it.

这个程序里没有构建控制台

这个服务端构建时没有带上控制台的文件。接口和命令行照常可用。要带上控制台：先构建它，再用 webdist 标签构建服务端（命令同上）。构建控制台需要 Node 和 pnpm；正式发布的程序都带着它。
